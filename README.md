# WPS AI 企业版官网

面向企业的 WPS AI 产品与方案展示页，围绕文档、表格、演示、企业问数、AI 专家、应用、团队协作和自动化能力展开。

## 企业方案

- 企业基础方案：¥4,980 / 年，包含 10 万点 AI 使用量
- 企业进阶方案：¥46,800 / 年，包含 100 万点 AI 使用量

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

默认访问 `http://localhost:3000/`。

## 构建

```bash
npm run build
```

页面为产品方案设计稿，具体能力、价格与服务范围以实际发布和合同为准。
